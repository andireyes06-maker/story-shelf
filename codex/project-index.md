## When Drafting a Chapter

1. `Story/Arc_01_Yamashiro/ARC_01_PLAN.md` — which movement, what does it require?
2. `Story/Arc_01_Yamashiro/ARC_01_CAST.md` — which recurring character(s) are live?
3. `Bible/04_CONTINUITY_AND_MYSTERIES.md` — what must *not* be revealed yet?
4. `Bible/02_CHARACTERS.md` / `Bible/03_MAGIC_AND_SYSTEM.md` — as needed.
5. `Craft/WRITING_RULEBOOK.md` — the chapter-prompt template and relevant prose rules.
